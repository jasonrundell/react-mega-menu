# Releasing v3.0.0

v3.0.0 shipped (issue #98). This records what changed since `3.0.0-beta.0` and
how the release was published, for reference on future releases.

## What's in v3.0.0

- `package.json` at `3.0.0`, React 19 / Topiary peer dependencies, Emotion
  removed, `./style.css` and `types` exports in place.
- `npm run build` emits `dist/index.es.js`, `dist/index.cjs`, `dist/style.css`,
  `dist/index.d.ts` and `dist/index.d.cts`.
- README rewritten: install, stylesheet imports, `data-theme`, the `--rmm-*`
  token table (contract-tested against the stylesheet), `slideDirection`, v2 to
  v3 migration notes, v2.x marked as the React 18 line.
- Accessibility gate: axe scans in every state in `npm test`; keyboard
  walkthrough recorded in `docs/accessibility/keyboard-walkthrough.md`.
- The off-canvas nav and every mega / sub panel paint their own chrome
  (`--rmm-panel-bg`, `--rmm-panel-border`, `--rmm-panel-shadow`,
  `--rmm-panel-padding`), the shell and panels have a gutter (`--rmm-gutter`),
  mega panels lay out as a grid of columns (`--rmm-column-min-width`), links
  hover as rounded pills (`--rmm-link-radius`), and chevrons are drawn in CSS
  (`--rmm-icon-stroke`, `--rmm-line-height`).
- `slideDirection` applies to the mega and sub panels as well as the nav, so
  every level of the mobile menu enters from the same side.
- Both demos install the release tarball; the Vite demo was restyled and gained
  a `/slide-right/` page; the Next demo's padding clears the fixed top bar.

## How it was published

Tags in this repo are unprefixed (`2.2.2`, `3.0.0`, not `v3.0.0`), so
`npm version`'s default `v` prefix was bypassed:

```sh
npm version 3.0.0 --no-git-tag-version   # bumped package.json / lockfile only
npm run pack:demo                        # refreshed the committed tarball for the demos
# updated demo/package.json and next-demo/package.json to the 3.0.0 tarball, reinstalled both
git commit -am "3.0.0" && git tag 3.0.0
git push && git push origin 3.0.0
```

Then "Publish to npm" was run from the Actions tab
(`.github/workflows/npm-publish.yml`, `workflow_dispatch`), which derives
`latest` from the non-pre-release version. Verified afterward:

- `npm view @jasonrundell/react-mega-menu dist-tags` shows `latest: 3.0.0`.
- Both demos reinstalled `@jasonrundell/react-mega-menu@latest` from the
  registry (not the tarball) and were walked in a browser: four Topiary themes
  via `?theme=`, both `slideDirection` values below the `large` breakpoint on
  `/` and `/slide-right/`.
- `publint` and `arethetypeswrong` against the published tarball: the `.` export
  is green on node10, node16 (CJS and ESM) and bundler resolution.
  `arethetypeswrong` flags `./style.css` as a resolution failure in every mode,
  which is expected — a stylesheet has no type declarations to resolve and none
  are exported for it. publint's two suggestions — `engines.node` and
  `sideEffects` — are pre-existing and out of scope for this release.

The CommonJS entry ships as `dist/index.cjs` with its own `index.d.cts`, so
`require()` consumers resolve real CommonJS.
