# Releasing v3.0.0

The maintainer's checklist for shipping v3 (issue #98). Everything above the
"Publish" line is done on the branch and verified by `npm test`; the publish and
tag steps are manual and need npm and GitHub credentials.

## Already on the branch

- [x] `package.json` at `3.0.0-beta.0`, React 19 / Topiary peer dependencies,
      Emotion removed, `./style.css` and `types` exports in place.
- [x] `npm run build` emits `dist/index.es.js`, `dist/index.cjs.js`,
      `dist/style.css` and `dist/index.d.ts`.
- [x] Both demos install the beta tarball
      (`jasonrundell-react-mega-menu-3.0.0-beta.0.tgz`), typecheck / lint and
      build. The Next demo's SSR proof is recorded in its README.
- [x] README rewritten: install, stylesheet imports, `data-theme`, the `--rmm-*`
      token table (contract-tested against the stylesheet), `slideDirection`, v2
      to v3 migration notes, v2.x marked as the React 18 line.
- [x] Accessibility gate: axe scans in every state in `npm test`; keyboard
      walkthrough recorded in `docs/accessibility/keyboard-walkthrough.md`.

## Publish the beta

```sh
npm ci && npm test
npm publish --tag beta          # publishes 3.0.0-beta.0 under the "beta" dist-tag
```

Verify the published package (not the tarball) in both demos:

```sh
cd demo && npm install @jasonrundell/react-mega-menu@beta && npm run build && npm run dev
cd ../next-demo && npm install @jasonrundell/react-mega-menu@beta && npm run build && npm start
```

Walk both demos in a browser: four themes via `?theme=`, both `slideDirection`
values below the `large` breakpoint, keyboard rows 4 and 12 of the walkthrough
with a physical keyboard (those two could not be automated). Then restore the
`file:` tarball specs if you want the demos to keep installing from the repo.

## Ship 3.0.0

```sh
npm version 3.0.0                # bumps package.json / lockfile, creates the v3.0.0 tag
npm run pack:demo                # refresh the committed tarball name for the demos
# update demo/package.json and next-demo/package.json to the 3.0.0 tarball, reinstall both
git push && git push --tags
npm publish                      # "latest" dist-tag
```

Before publishing, decide on the CommonJS entry: `dist/index.cjs.js` is a `.js`
file inside a `"type": "module"` package, so `require()` consumers resolve it as
ESM (flagged by publint and arethetypeswrong). Renaming the output to
`index.cjs` and adding `index.d.cts` clears it; it is not covered by any v3
ticket.
